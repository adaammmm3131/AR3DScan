# 📱 Guide : Installer l'app sur votre iPhone (GRATUIT, sans Mac)

## 🎯 Solution recommandée : AltStore (100% gratuit)

### Étape 1 : Télécharger AltStore

1. Allez sur **https://altstore.io**
2. Téléchargez **AltServer pour Windows**
3. Installez AltServer sur votre PC

### Étape 2 : Installer AltStore sur votre iPhone

1. **Connectez votre iPhone au PC** via câble USB
2. **Lancez AltServer** sur Windows (dans la barre système)
3. **Cliquez sur "Install AltStore"** → Sélectionnez votre iPhone
4. **Connectez votre iPhone au même Wi-Fi** que votre PC
5. **Ouvrez AltStore** sur votre iPhone (acceptez les certificats)

### Étape 3 : Générer le fichier .ipa

1. Allez sur GitHub Actions : **https://github.com/adaammmm3131/AR3DScan/actions**
2. Cliquez sur **"Build iOS App for Real Device"** (workflow en haut)
3. Cliquez sur **"Run workflow"** → **"Run workflow"**
4. Attendez **5-10 minutes** pour la compilation
5. Téléchargez l'artefact **"ios-device-build"**
6. Extrayez le fichier **`AR3DScan.ipa`**

### Étape 4 : Installer l'app sur votre iPhone

1. **Ouvrez AltStore** sur votre iPhone
2. Allez dans l'onglet **"My Apps"**
3. Appuyez sur **"+"** en haut à gauche
4. **Sélectionnez** le fichier `AR3DScan.ipa` depuis votre iPhone
5. **Saisissez votre Apple ID** et mot de passe
6. L'app sera installée ! ✅

## ⚠️ Important : Limitation des 7 jours

- L'app **expire après 7 jours** (Apple ID gratuit)
- **AltStore peut renouveler automatiquement** en arrière-plan
- Vous devez ouvrir AltStore sur votre iPhone **au moins une fois par semaine**
- Maximum **3 apps** installées à la fois

## 🔄 Alternative : Sideloadly (plus simple)

1. Téléchargez **Sideloadly** : https://sideloadly.io
2. Connectez votre iPhone au PC
3. Ouvrez Sideloadly
4. Glissez le fichier `.ipa` dans Sideloadly
5. Saisissez votre Apple ID
6. Cliquez sur **"Start"**

## 🆘 Problèmes courants

**"Unable to verify app"** :
→ L'app a expiré, réinstallez via AltStore

**"Developer Mode" requis (iOS 16+)** :
→ Réglages → Confidentialité et sécurité → Mode développeur → Activé

**L'app ne s'installe pas** :
→ Vérifiez que votre iPhone est connecté au même Wi-Fi que votre PC
→ Redémarrez AltServer sur Windows

## 📝 Notes

- **Sans compte développeur payant**, l'app doit être réinstallée tous les 7 jours
- AltStore peut renouveler automatiquement les apps si configuré
- Les fonctionnalités AR/Caméra fonctionnent normalement
- Cette méthode est **100% légale et gratuite**
